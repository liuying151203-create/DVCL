# DVCL 实验代码迁移说明

公开实验框架位于 `src/dvcl_bench/`，负责分离数据划分、攻击和训练随机种子，并统一运行清单与输出路径。

本公开仓库不包含无明确许可证的 HSeCo 作者源码或兼容快照，也不能依赖这类私有代码产生正式结果。HSeCo 基线采用依据正式论文独立实现的 `native` 模型。

模型迁移分为两类：

1. DVCL 及自行设计模块迁移到公开 `native` 适配器，并在固定实验产物上核对预测、验证集选择和测试指标。
2. 外部基线优先使用有明确许可证的官方实现或 OpenHGNN 适配器；HSeCo 只能根据已核实论文独立重写，具体要求见 `hseco_reimplementation.md`。

只有完成审计的原生适配器才能进入 `dvcl_main` 主表。作者报告数字、原论文协议复现结果和统一协议结果必须分开保存。
