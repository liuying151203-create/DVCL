# HSeCo 独立重写规范

## 当前状态

公开仓库不包含 HSeCo 原作者源码、无许可证的代码快照或由其直接修改得到的派生实现。现有私有兼容代码只用于核对历史实验，不是公开实现。

HSeCo 的正式论文已确认为 Chongjie Zhao、Jinyan Wang、Linlin Su、Zeming Gan、Ziyang Zhou 发表于 CIKM 2025 的《Robust Heterogeneous GNNs via Semantic Attention and Contrastive Learning》，DOI 为 `10.1145/3746252.3761343`，页码为 4326–4335。论文正文已归档并完成方法与实验设置提取。由于论文未公开若干关键实现细节，当前实现应标记为“依据论文独立实现”，在完成训练适配和行为验证前不能声称与作者实现完全等效。

## 独立重写要求

正式实现前必须先冻结以下公开依据：

1. 论文正式题名、作者、发表年份、DOI 或稳定链接；
2. 方法公式、伪代码、数据预处理和元路径定义；
3. 数据划分、训练轮数、早停、优化器和超参数范围；
4. 攻击方法、扰动预算、攻击目标和评估指标；
5. 论文允许公开引用的补充材料。

实现者只能依据上述公开材料编写 `native` 后端，不得查看或复制私有参考源码中的模型实现。私有参考代码只能由另一名审计者用于黑盒输入输出核对，不能向实现者传递源码细节。

## 验证标准

独立实现完成后至少执行：

- 单元测试：张量形状、掩码、元路径和损失函数；
- 协议测试：固定划分、固定攻击图以及相互独立的随机种子；
- 行为测试：论文中的消融趋势和关键超参数趋势；
- 复现实验：按照论文协议报告多随机种子均值与标准差；
- 统一实验：在 `dvcl_main` 中与其他方法使用相同产物和调参预算。

论文原始数字、论文协议复现数字和 DVCL 统一协议重跑数字必须分开记录。只有通过上述检查的实现，才可标记为“依据论文独立复现的 HSeCo”。
