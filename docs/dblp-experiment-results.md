## 1. 实验设置

当前结果为 DBLP 上的全局结构 poisoning 实验，包括 clean、PRBCD 和
HetePRBCD，不包含目标攻击和消融实验。HAN、HeteroSAGE、HSeCo 与 DVCL 使用相同
的数据、划分、攻击 artifact 和随机种子。

| 设置 | 取值 |
|---|---|
| 数据集 | DBLP |
| Protocol | `dblp_poisoning_main_v1` |
| 数据划分 | `paper_seed_1` |
| 划分种子 \(s_{\mathrm{split}}\) | 1 |
| 攻击种子 \(s_{\mathrm{atk}}\) | 1 |
| 训练种子 \(s_{\mathrm{train}}\) | 1, 2, 3, 4, 5 |
| 攻击率 | 5%, 10%, 15%, 20%, 25% |
| 最大训练轮数 \(E_{\max}\) | 200 |
| 早停耐心值 \(P\) | 100 |
| 优化器 | Adam |
| checkpoint | 完整原生模型 |
| GPU | Tesla V100-PCIE-32GB，`cuda:0`–`cuda:3` |
| PRBCD | `constrained=true`，`biased=false` |
| HetePRBCD | `constrained=true`，`biased=true`，\(\lambda=0.4\) |
| 攻击关系 | Author–Paper（A–P）及其反向关系 |
| 预算分母 | clean 图全部正向关系边数 |

表中结果均为 5 个训练种子的均值 ± 样本标准差，单位为百分数。当前任务为
单标签多分类，Accuracy 与 Micro-F1 数值相同，因此统一记为
`Accuracy / Micro-F1`。

## 5. 结果分析

1. 修正协议的四个 clean 均值和标准差与旧主实验一致，说明本轮变化来自攻击
   artifact，而不是模型配置或 clean 训练流程变化。
2. PRBCD Average 上 HAN 为 88.54，HSeCo 为 88.36，DVCL 为 87.11。DVCL
   在该攻击族不占优势，不能宣称对所有结构攻击都优于基线。
3. HetePRBCD Average 上 DVCL 达到 82.40，比 HSeCo 高 6.52 个百分点；在
   15% 和 20% 下分别高 8.92 和 11.05 个百分点。
4. 综合 10 个攻击条件，DVCL 的 Attack Average 为 84.75，比 HSeCo 高 2.63
   个百分点，并明显高于 HAN 和 HeteroSAGE。
5. HetePRBCD 各 artifact 的训练节点扰动占比为 93.58%–99.60%。这是使用训练
   mask 优化的 poisoning 攻击行为，解释结果时必须与测试时目标逃逸攻击区分。
6. 攻击率表示预算上限，但独立优化得到的 artifact 难度不保证严格单调。HAN 在
   HetePRBCD 25% 下为 28.93 ± 8.53，表明不同训练 seed 存在明显不稳定性。
