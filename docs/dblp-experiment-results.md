# DBLP 实验结果

## 1. 实验设置

当前结果为 DBLP 上的全局结构 poisoning 实验，包括 clean、PRBCD 和
HetePRBCD，不包含目标攻击和消融实验。HSeCo 与 DVCL 使用相同的数据、划分、
攻击 artifact 和随机种子。

| 设置 | 取值 |
|---|---|
| 数据集 | DBLP |
| 数据划分 | `paper_seed_1` |
| 划分种子 \(s_{\mathrm{split}}\) | 1 |
| 攻击种子 \(s_{\mathrm{atk}}\) | 1 |
| 训练种子 \(s_{\mathrm{train}}\) | 1, 2, 3, 4, 5 |
| 攻击率 | 5%, 10%, 15%, 20%, 25% |
| 最大训练轮数 \(E_{\max}\) | 200 |
| 早停耐心值 \(P\) | 100 |
| 优化器 | Adam |
| checkpoint | 完整原生模型 |
| GPU | Tesla V100-PCIE-32GB |

表中结果均为 5 个训练种子的均值 ± 样本标准差，单位为百分数。当前任务为
单标签多分类，Accuracy 与 Micro-F1 数值相同，因此统一记为
`Accuracy / Micro-F1`。

## 4. 攻击平均结果

先在每个训练种子内对同一攻击族的攻击条件取平均，再计算 5 个训练种子间的
均值和样本标准差。Attack Average 包含全部 10 个攻击条件，不包含 clean。

**表 2：DBLP 攻击平均 Accuracy / Micro-F1。**

| Condition | HSeCo | DVCL | \(\Delta\) |
|---|---:|---:|---:|
| Clean | 89.14 ± 0.50 | **89.55 ± 0.64** | +0.41 |
| PRBCD Average | 88.45 ± 0.22 | **88.91 ± 0.56** | +0.46 |
| HetePRBCD Average | 76.30 ± 0.87 | **82.85 ± 1.00** | +6.55 |
| Attack Average | 82.38 ± 0.46 | **85.88 ± 0.72** | +3.50 |

## 5. 结果分析

1. DVCL 在 clean 和 10 个攻击条件中的 9 个条件下优于 HSeCo，仅在 PRBCD
   5% 下低 0.22 个百分点。
2. DVCL 的 Attack Average 比 HSeCo 提升 3.50 个百分点，表明双视图机制能
   提升整体结构攻击鲁棒性。
3. 在 PRBCD 下，DVCL 平均提升 0.46 个百分点；在面向异构图的 HetePRBCD
   下，平均提升达到 6.55 个百分点，主要优势来自更强的异构结构攻击防御能力。
4. HetePRBCD 15% 和 20% 下的提升分别达到 8.83 和 9.41 个百分点，是当前
   DBLP 主实验中最显著的改进。
5. 攻击率表示扰动预算，但具体攻击 artifact 的难度不保证严格单调，因此不同
   攻击率下的小幅波动不应解释为性能随攻击增强而提升。
