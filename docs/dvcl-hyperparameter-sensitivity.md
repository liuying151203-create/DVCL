# DVCL 超参数敏感性实验

## 实验设置

- 数据集：DBLP；最终模型固定为 `concat + graph_hard`。
- 条件：clean 与 HetePRBCD $r=15\%$；配对重复 $(s_a,s_t)=(1,1),(2,2),(3,3)$。
- 单因素取值：$\lambda_h,\lambda_d\in\{0,0.1,0.5,1,2\}$，$\tau\in\{0.1,0.2,0.5,1,2\}$，$k\in\{5,10,20,40,80\}$，$K\in\{1,2,4,8\}$。
- 参照值：$(\lambda_h,\lambda_d,\tau,k,K)=(1,1,0.5,20,4)$；$E_{max}=200$，$P=100$；仅报告 Micro-F1。
- `配对 Δ` 为相同 $(s_a,s_t)$ 下当前取值相对公共参照的 Micro-F1 均值差。
- 本实验只描述敏感性，不根据结果修改已冻结的论文主模型。
