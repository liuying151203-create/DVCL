## 1. 实验设置

- 数据集：ACM、DBLP、AMiner；单种子机制 Pilot，$(s_a,s_t)=(1,1)$。
- 模式：`topo`、`feat`、`concat`、`gate`、`gated_concat`。
- 攻击：HG Baseline 迁移攻击与每模型独立优化的 64+64 候选自适应查询攻击。
- 预算：$\Delta=\{1,3,5\}$；结果只报告 Micro-F1。
- 自适应攻击和 HG 使用各自冻结的目标集，绝对 Micro-F1 不跨攻击类型直接比较。
- 最终审计核对实验规格、输入路径、输入 SHA-256 和 victim checkpoint 身份。

## 6. 分析与阶段 E 决策

- DBLP 自适应攻击下，`topo` 的 Drop@5 为 62.00 pp，`feat` 为 0.00 pp。
- Feature embedding 漂移为 0 是威胁模型的预期结果：攻击只修改异构结构边，特征 KNN 图和节点特征保持冻结。
- DBLP 的双视图预测分歧在 `concat` 中由 26.00→50.00；但 `gate` 的拓扑权重由 0.7589→0.7627，`gated_concat` 由 0.9116→0.9054，没有在拓扑失真时显著降低。
- 最佳已有门控候选为 `gate`：相对 `concat` 的 DBLP 攻击后增益为 -4.00 pp，三数据集最大 clean 损失为 1.14 pp，ACM/AMiner 最大攻击后损失为 0.00 pp。
- 预注册门槛判定：未通过；下一步应进入 `reliability_gate` 单种子机制 Pilot。
- 本结果为单种子机制 Pilot，只用于选择阶段 E 路线，不作为论文显著性结论。
- 75 个运行 manifest 标记为 dirty worktree；本阶段仅作机制筛选，正式论文证据必须在冻结提交上重跑。
