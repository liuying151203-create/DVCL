# HSeCo 论文实现规格

本文档仅依据 Zhao 等发表于 CIKM 2025 的论文《Robust Heterogeneous GNNs via Semantic Attention and Contrastive Learning》（DOI：`10.1145/3746252.3761343`）整理，不以私有参考源码作为实现依据。

## 方法流程

HSeCo 包含两个联合训练模块：

1. 语义感知边权注意力：按预定义元路径构造多个目标节点语义图，将特征投影到共享空间，计算边相似度并在每个源节点的邻居内归一化；使用元路径特定阈值净化各语义图，再通过共享多头编码器获得视图表示。
2. 结构感知对比优化：用 HAN 风格语义注意力计算各元路径权重，融合各视图边权并按全局阈值再次剪枝；对净化全局图生成扰动视图，使全局表示接近各净化语义视图、远离扰动视图。

论文目标函数为：

```text
L = L_CE + λ L_CL
```

其中 `L_CE` 是训练节点上的交叉熵，`L_CL` 使用余弦相似度构造全局图与各净化视图的正对，以及全局图与扰动视图的负对。

## 数据与攻击

- 数据集：DBLP、ACM、AMiner。
- 元路径：DBLP 使用 APA、APTPA、APCPA；ACM 使用 PAP、PSP；AMiner 使用 PAP、PRP。
- 指标：Micro-F1。
- 中毒攻击：PRBCD、HetePRBCD，扰动率为 0、5、10、15、20、25。
- 逃逸攻击：HG Baseline，预算为 0、1、3、5；ACM、DBLP 攻击 P-A 边，AMiner 攻击 P-R 边。
- 基线：GCNJaccard、EGCNGuard、RGCN、SimPGCN、RoHe、HeteroSAGE、HeteroGuard、FastRoHGCN。
- 消融：移除语义感知边权模块的 HSeCo-c；移除结构对比模块的 HSeCo-s。

## 论文未明确的实现项

论文没有给出以下信息，不能从原论文结果反推：

- 相似度函数 `φ` 的具体形式；
- 每条元路径阈值和全局阈值的数值；
- 扰动视图采用特征打乱还是边打乱，以及扰动比例；
- 多头数、隐藏维度、优化器、学习率、权重衰减和训练轮数；
- 训练、验证、测试划分及随机种子；
- `λ` 的最终取值和搜索范围；
- 早停与模型选择规则。

原生实现将这些字段保留为显式配置。当前代码用余弦相似度作为 `φ` 的复现假设，但正式实验前必须在验证集上统一选择并冻结所有缺失项，同时在论文中披露。

## 实现边界

`src/dvcl_bench/models/hseco.py` 实现论文公式对应的模型核心，不负责数据下载、划分、攻击生成或训练调参。训练适配器必须读取 DVCL Bench 已冻结的语义图、划分和攻击产物。

该实现应称为“依据论文独立实现”或“paper-derived reimplementation”，不能称为作者官方实现。只有在公式测试、消融趋势和多随机种子实验均通过后，才能进入 `dvcl_main` 主表。
