# HG Baseline 目标逃逸实验结果

## 实验设置

- 数据集：ACM、DBLP；固定 split seed 1、attack seed 1，train seed 1–5。
- 威胁模型：模型在 clean 图上训练，仅在测试时按目标节点替换攻击图；`adaptive=false`。
- 攻击：HG Baseline，$\Delta\in\{1,3,5\}$；ACM 攻击 500 个 paper，DBLP
  攻击 372 个 author。
- 指标：固定目标节点上的 Micro-F1，五次运行均值 $\pm$ 样本标准差，单位为百分数。
- 审计：`330/330` 完成、零失败；全部 manifest 对应提交 `14c2cdd` 且
  `git_dirty=false`。

## 分析

1. 攻击链路有效。HAN、MAGNN、SimpleHGN 和 FastRoHGCN 随 $\Delta$ 增大均出现
   大幅下降；DBLP HAN 在 $\Delta=5$ 时从 94.14 降至 5.11。
2. ACM 上 DVCL、RoHe、HSeCo、HeCo 和 HeteroGuard 的下降很小，其中 RoHe 有轻微
   上升。这表示当前固定 HG Baseline 扰动没有有效破坏这些模型，而不是攻击未执行。
3. DBLP 上所有模型均下降。DVCL 在三个扰动率下均取得最高攻击后 Micro-F1；
   HeteroGuard 与 HGT 的 Drop@5 更小，但其 clean-target 起点也更低。
4. 本表是 `adaptive=false` 的目标逃逸评估，不代表针对 DVCL 或各鲁棒模型优化的
   自适应攻击结果，也不与 poisoning Attack Average 合并。
