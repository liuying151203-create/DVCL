## 4. 分析

1. HG Baseline 衡量固定攻击的跨模型迁移效果，不能替代自适应鲁棒性结论。
2. 自适应攻击与具体训练 checkpoint 绑定，直接优化 DVCL 的分类间隔。
3. 不同数据集的目标集合规模不同，只在同一数据集内比较模型和扰动预算。
