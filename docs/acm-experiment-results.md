# ACM 实验结果

> 协议审计状态：`acm_poisoning_main_v1` 已完成 220/220 次主实验，
> `acm_poisoning_ablation_v1` 已完成 140/140 次消融实验。全部运行来自干净提交，
> 修正后的 PRBCD/HetePRBCD artifact 均通过 provenance、预算和反向边验证。

## 1. 实验设置

当前结果为 ACM 上的全局结构 poisoning 实验，包括 clean、PRBCD 和
HetePRBCD，不包含目标攻击。HAN、HeteroSAGE、HSeCo 与 DVCL 使用相同的数据、
划分、攻击 artifact 和随机种子。

| 设置 | 取值 |
|---|---|
| 数据集 | ACM |
| 主实验 Protocol | `acm_poisoning_main_v1` |
| 消融 Protocol | `acm_poisoning_ablation_v1` |
| 数据划分 | `paper_seed_1` |
| 划分种子 \(s_{\mathrm{split}}\) | 1 |
| 攻击种子 \(s_{\mathrm{atk}}\) | 1 |
| 训练种子 \(s_{\mathrm{train}}\) | 1, 2, 3, 4, 5 |
| 主实验攻击率 | 5%, 10%, 15%, 20%, 25% |
| 消融实验攻击率 | 5%, 15%, 25% |
| 最大训练轮数 \(E_{\max}\) | 200 |
| 早停耐心值 \(P\) | 100 |
| 优化器 | Adam |
| checkpoint | 完整原生模型 |
| GPU | Tesla V100-PCIE-32GB，`cuda:1`–`cuda:4` |
| PRBCD | `constrained=true`，`biased=false` |
| HetePRBCD | `constrained=true`，`biased=true`，\(\lambda=0.4\) |
| 攻击关系 | Author–Paper（A–P）及其反向关系 |
| 预算分母 | clean 图全部正向关系边数 |

表中结果均为 5 个训练种子的均值 ± 样本标准差，单位为百分数。当前任务为
单标签多分类，Accuracy 与 Micro-F1 数值相同，因此统一记为
`Accuracy / Micro-F1`。

## 6. 结果分析

1. 修正协议的四个 clean 结果与旧主实验一致，说明本轮差异来自攻击 artifact，
   而不是模型配置或 clean 训练流程变化。
2. DVCL 的 Attack Average 为 88.06，比 HSeCo 高 1.92 个百分点，并高于 HAN
   和 HeteroSAGE；PRBCD Average 上 HAN 仍比 DVCL 高 0.30 个百分点。
3. HetePRBCD Average 上 DVCL 为 88.07，比 HSeCo 高 1.80 个百分点。HAN 在
   15%–25% 下标准差达到 8.64–10.90，说明其训练结果明显不稳定。
4. 移除跨视图对比学习和特征视图后，Attack Average 分别下降 0.63 和 2.02 个
   百分点，特征视图是当前增益的主要来源。
5. 移除拓扑视图后，各攻击条件与 clean 完全相同，因为当前攻击只修改拓扑，
   固定特征 KNN 图不随攻击变化。
6. PRBCD 与 HetePRBCD 的训练节点扰动占比分别为 83.23%–91.62% 和
   89.88%–98.62%。这是使用训练 mask 优化的 poisoning 行为，不能解释为测试时
   目标逃逸攻击。
7. 攻击率表示扰动预算，但独立优化得到的 artifact 难度不保证严格单调，不应将
   局部波动解释为性能随攻击增强而提升。
