# ACM 实验结果

> 协议审计状态：clean 结果有效；PRBCD/HetePRBCD 结果暂定，需使用显式开启
> semantic constraints、且 HetePRBCD 同时开启 biased sampling 的新 artifact 重跑。

## 1. 实验设置

当前结果为 ACM 上的全局结构 poisoning 实验，包括 clean、PRBCD 和
HetePRBCD，不包含目标攻击。HSeCo 与 DVCL 使用相同的数据、划分、攻击
artifact 和随机种子。

| 设置 | 取值 |
|---|---|
| 数据集 | ACM |
| 数据划分 | `paper_seed_1` |
| 划分种子 \(s_{\mathrm{split}}\) | 1 |
| 攻击种子 \(s_{\mathrm{atk}}\) | 1 |
| 训练种子 \(s_{\mathrm{train}}\) | 1, 2, 3, 4, 5 |
| 主实验攻击率 | 5%, 10%, 15%, 20%, 25% |
| 消融实验攻击率 | 5%, 15%, 25% |
| 最大训练轮数 \(E_{\max}\) | 200 |
| 早停耐心值 \(P\) | 100 |
| 优化器 | Adam |
| checkpoint | 完整原生模型 |
| GPU | Tesla V100-PCIE-32GB |

表中结果均为 5 个训练种子的均值 ± 样本标准差，单位为百分数。当前任务为
单标签多分类，Accuracy 与 Micro-F1 数值相同，因此统一记为
`Accuracy / Micro-F1`。

## 6. 结果分析

1. DVCL 在 clean 和全部 10 个全局攻击条件下均优于 HSeCo，Attack Average
   提升 1.86 个百分点。
2. 移除跨视图对比学习后，Attack Average 下降 1.00 个百分点，说明跨视图
   一致性约束能够提升整体鲁棒性。
3. 移除特征视图后，Attack Average 下降 2.08 个百分点，说明独立于受攻击
   拓扑的特征视图是主要增益来源。
4. 移除拓扑视图后，各攻击条件与 clean 结果相同，因为当前攻击只修改拓扑，
   固定特征 KNN 图不随攻击变化。
5. 攻击率表示扰动预算，但具体攻击 artifact 的难度不保证严格单调，因此不同
   攻击率下的小幅波动不应解释为性能随攻击增强而提升。
